# Static portfolio

Open index.html in a browser or upload this folder to any static host. No build, PHP runtime, database or login is required.

Edit the HTML files to update content. The CSS, JavaScript, images and original resume content are retained. The home page's View Resume button opens resume.html because no downloadable CV was supplied.

The upload did not contain a database export. Project titles, descriptions, categories and certificate metadata could not be recovered. All supplied project images and certificate files are linked using generic labels; replace those labels and the project detail placeholders directly in the HTML. Project images are presented individually because their original grouping is unknown.

The contact form opens a mailto draft and requires the visitor to send it using an email app. There is no server submission or message storage.

Google Fonts, Font Awesome and the existing blog's external demo links/images need internet access. Blog content is inherited template content; replace it before publishing.

Admin, authentication and database files have been removed.

The resume's Print / Save CV button opens the browser print dialog, where visitors can save a PDF. All 13 HTML pages have been checked for missing local page/image/script links. The original theme stylesheet is unchanged. Some inherited theme CSS references WordPress font/image paths that were not supplied; exact visual equivalence to the original live site has not been verified.
